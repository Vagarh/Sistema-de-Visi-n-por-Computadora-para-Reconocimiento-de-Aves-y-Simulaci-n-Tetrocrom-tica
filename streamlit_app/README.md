# 🦅 Aplicación Streamlit - Visión Tetrocromática

## 🚀 Ejecución Rápida

```bash
streamlit run app.py
```

## 📁 Archivos

- `app.py` - Aplicación principal
- `utils.py` - Utilidades avanzadas
- `.streamlit/config.toml` - Configuración local
- `.streamlit/config_cloud.toml` - Configuración para Streamlit Cloud

## 🔧 Deployment

Para subir a Streamlit Cloud:

```bash
python ../scripts/prepare_deployment.py
```

Luego sigue las instrucciones en `../docs/DEPLOYMENT_INSTRUCTIONS.md`

## 📊 Funcionalidades

- 🖼️ Carga de imágenes (archivo o ejemplos)
- 🔬 Predicción de canal UVB
- 📊 Análisis EDA avanzado
- 🧠 Extracción de embeddings
- 📈 Clustering y métricas
- 🌳 Cladogramas comparativos
- 🔧 Panel técnico avanzado
